Healthcare Analytics Dashboard (Tableau)
📊 Project Overview

This repository contains a Tableau Dashboard designed to analyze and visualize healthcare-related data for better insights and decision-making. The dashboard presents key metrics, trends, and comparisons in an interactive and user-friendly manner, helping stakeholders understand patterns in healthcare performance and outcomes.

The Tableau packaged workbook file (.twbx) includes all data sources, calculations, and visualizations bundled together for easy access.

🗂️ File Included

Healthcare.twbx – Tableau Packaged Workbook containing:

Integrated data sources

Calculated fields and filters

Interactive dashboards and worksheets

🎯 Objectives

Analyze healthcare data using visual analytics

Identify trends, patterns, and key performance indicators (KPIs)

Enable data-driven insights through interactive dashboards

Present complex healthcare data in a simple and intuitive format

🧩 Key Features

Interactive filters and parameters

Clear visual representation of healthcare metrics

User-friendly dashboard layout

Dynamic charts and graphs for easy comparison

🛠️ Tools & Technologies

Tableau Desktop / Tableau Public – for data visualization and dashboard development

Data Source – Embedded within the .twbx file

🚀 How to Use

Download or clone this repository

Open Healthcare.twbx using Tableau Desktop or Tableau Public

Interact with filters, charts, and dashboards to explore insights

📌 Use Cases

Academic projects and presentations

Healthcare data analysis and reporting

Learning and practicing Tableau dashboard development
